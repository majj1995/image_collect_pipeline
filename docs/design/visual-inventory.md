# 素材扩展台视觉清单

## 视觉源与验收

- 源图：`docs/design/collection-workbench-concept.png`（1586 × 992，目标视口 1600 × 1000）。
- 接受原因：完整呈现深色顶栏、分类队列、广告素材画廊、溯源详情和唯一主导出动作；广告图像比例清晰，权利/来源信息紧凑可扫读，没有营销页式首屏、装饰性指标、玻璃效果或默认 Bento 卡片墙。
- 实现原则：源图是整个应用的视觉规格，不作为界面截图嵌入；应用文字、表单、表格、按钮和图标全部使用 React/HTML/CSS 原生实现。

## 设计令牌

### 颜色

| 用途 | 颜色 |
| --- | --- |
| 顶栏 / 强对比底色 | `#151A21` |
| 顶栏次级底色 | `#202630` |
| 页面、表面与媒体底色 | `#FFFFFF` |
| 冷白次级底色 | `#F7F9FC` |
| 主文字 | `#151922` |
| 次文字 | `#667085` |
| 弱文字 | `#98A2B3` |
| 分隔线 / 控件边框 | `#E3E7ED` |
| 选中与主操作钴蓝 | `#1768F2` |
| 选中浅底 | `#EAF2FF` |
| 可用 / 权利明确 | `#148A62` |
| 注意 / 权利待确认 | `#B7791F` |
| 拒绝 / 错误 | `#D64545` |

背景锁定为冷白或真白，不改成米白、奶油色或暖灰；不使用渐变、光晕、半透明洗色层。

### 排版

- 字体：`Inter`, `PingFang SC`, `Microsoft YaHei`, system-ui, sans-serif。不依赖远程字体。
- 页面标题：24 px / 32 px，600。
- 区域标题：16 px / 24 px，600。
- 正文与表格：14 px / 21 px，400–500。
- 控件文字：13 px / 20 px，500。
- 辅助信息：12 px / 18 px，400。
- 数据标识：优先使用 tabular numerals；不使用浏览器默认按钮字号。

### 几何与间距

- 基础间距：4, 8, 12, 16, 20, 24, 32 px。
- 顶栏：56 px 高；页面水平留白 28–32 px。
- 控件高度：32 px 紧凑型，40 px 主操作，表单字段 40–44 px。
- 圆角：输入框/按钮 6 px，媒体框 8 px，对话框 12 px；列表行和大区域不额外包裹巨型圆角卡片。
- 阴影：仅浮层使用 `0 16px 40px rgb(16 24 40 / 14%)`；日常分区靠 1 px 分隔线。

## 容器模型与布局

- 全局：顶栏 + 内容平面，不用营销页英雄区。
- 任务页：标题/主操作工具行 + 开放式表格列表；禁止改成卡片网格。
- 工作台：260 px 分类轨道 + 流式画廊 + 380 px 溯源检查器。画廊图像使用稳定 aspect-ratio，单层紧凑信息条，不嵌套卡片。
- 设置页：提供方状态表 + 少量必要的权利声明控件，不显示密钥原文。
- 对话框：桌面端最宽 720 px，小屏从底部全宽展开。

## 图标

- 使用 Lucide 线性图标，默认 16 px、1.75 px 笔画、round cap/join；空状态可用 24 px。
- 方向、收起、设置、搜索、刷新、关闭、下载都使用矢量图标，不用纯文本字符替代。
- 状态色只表达语义，同时配合文字/图标，不仅靠颜色。

## 允许的首屏文案

### 全局顶栏

`素材扩展台`、`采集任务`、`提供方`、`本地服务已连接`（异常时可置换为明确的中文状态）。

### 任务列表与建单

`采集任务`、`新建采集任务`、`任务名称`、`任务类型`、`标签路径`、`执行状态`、`候选数`、`已选数`、`最后更新`、`操作`、`创建并进入工作台`，以及需求明确要求的字段名、解析错误和空状态。

### 工作台

`分类队列`、`全选`、`已选`、`继续搜索`、`暂停`、`仅看未审核`、`图片格式`、`比例`、`来源`、`授权类型`、`更多筛选`、`素材溯源与信息`、`溯源信息`、`扩展记录`、`版权与使用`、`文件信息`、`校验信息`、`导出数据集`，以及真实数据值和必要审核状态。

## 交互状态

- 按钮：默认、hover（亮度 -5%）、focus-visible（2 px 钴蓝外环）、pressed（轻微下移 1 px）、disabled（45% 透明度）。
- 列表行：hover 使用 `#F7F9FC`；选中使用左侧 3 px 钴蓝条和浅蓝底。
- 候选素材：默认灰边框，选中为 2 px 钴蓝，拒绝降低图像饱和度并显示文字，无效/隔离使用明确的警示层。
- 加载：保留媒体比例的中性骨架屏；失败不展示破图图标。
- 转场：120–180 ms 颜色/位置过渡；`prefers-reduced-motion` 时禁用位移动画。

## 响应式

- ≥1280 px：工作台三区同时可见，画廊自适应 3–4 列。
- 900–1279 px：分类轨道收窄至 220 px，溯源检查器作为右侧抽屉覆盖。
- <900 px：顶栏保留品牌和核心操作，次要导航收起；分类队列改为侧滑层，画廊 2 列。
- <640 px：任务表格使用可横向滚动的语义表格，画廊 1 列，对话框/抽屉全宽；主操作保持可见。

## 组件族

- `AppShell`：品牌、导航、连接状态和页面容器。
- `StatusBadge`：仅用于真实运行/权利/素材状态，小尺寸、低强度底色，不作装饰。
- `DataTable`：开放式表格，固定表头，整行可达，空状态不改变列结构。
- `Dialog`：标题、可滚动表单主体、固定底部操作，具备焦点锁定、Esc 关闭和语义化错误摘要。
- `Field`：显式 label、辅助文字、错误文字；默认值始终可见。
- `CandidateCard`：稳定媒体框、紧凑元数据行、语义状态和审核操作。
- `Inspector`：标签页/分组信息行，链接不显示查询字符串，密钥和原始响应永不显示。

## 生产资产清单

- 概念图中的商品广告图仅用于设计参考，不作为产品内置训练数据或搜索结果。
- 实际画廊只显示后端安全缓存生成的缩略图；空状态使用代码原生图标和文字，不需要额外点阵资产。

## 导出预检细节稿

- 源图：`docs/design/export-preflight-concept.png`（1586 × 992），仅规定对话框状态，延续主概念图的设计令牌。
- 结构锁定：模式选择 → 开放式审计行 → 真实阻塞解释 → 内部研发确认 → 固定底部操作。不将每个数字改造为统计卡片。
- 文案锁定：`导出数据集`、`严格合规`、`内部研发`、`已选素材`、`可导出`、`授权未知`、`提供方合约阻塞`、`标签冲突`、`素材缺失`、`我已确认这些素材仅用于内部研发，并理解授权状态未知`、`取消`、`生成 ZIP`。
- 语义锁定：严格模式不提供绕过；内部研发只能通过指定确认文案解除可确认的阻塞，不能绕过提供方合约禁止。按钮的 disabled/enabled 状态必须反映真实预检结果。
